# OBEMSTAR · Terminal

Web oficial de **OBEMSTAR**: portfolio, hub de tiendas y contacto.

🌐 **https://obemstar.github.io**

- **Interactive Division**: videojuegos
- **Industries**: impresión 3D
- **Núcleo 3D**: modelado, compartido por las dos divisiones

Estética de terminal sci-fi de los 80/2000 (Nostromo, Skynet) con usabilidad moderna. HTML, CSS y JavaScript puros: sin instalaciones ni compilación.

## Empezar

- Ver en local: doble clic en `index.html`.
- Añadir contenido: edita `js/contenido.js`.
- Publicar: commit + push (GitHub Pages).

Instrucciones completas en **[GUIA.md](GUIA.md)**.
